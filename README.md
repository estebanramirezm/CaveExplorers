# 🔦 Cave Explorers
A 2D Pixel-Art Platformer focused on light-based resource management and subterranean exploration.

## 🚀 How to Play
1. **Download:** Grab the latest release from the `Builds` folder (or your submitted binary).
2. **Launch:** Double-click the executable to start the game. 
3. **Setup:** No parameter files or manual configuration is required.

> **Note:** Certain features like the shop system and specific firefly ability unlocks are in the final playtesting phase. While functional, they represent the project's current development milestone.

---

## 🐞 Known Issues
* **Mid-air Climbing:** Pressing `X` to climb a vine can occasionally allow the player to move away from the wall while remaining in the climb state. Use with caution!
* **Edge Cases:** Players may encounter minor unverified interactions in specific biome transitions.
